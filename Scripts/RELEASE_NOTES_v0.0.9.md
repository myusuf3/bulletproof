## What's new in 0.0.9

Settings, redesigned in the System Settings style:

- Sidebar navigation with search - type "permission", "update", or "hotkey"
  and jump straight to the right pane.
- Five panes: General, Shortcut, Engine, Models, and a new About pane with
  version info, update check, and links.
- Every setting now explains itself with an inline description.
- Permission status (Accessibility, Notifications) lives with the shortcut
  it powers, with one-click fixes when something needs granting.
