## What's new in 0.0.15

- New Statistics pane in Settings: see what each engine did (applied,
  unchanged, rejected), why corrections were rejected, and where the time
  goes - all measured on this Mac, nothing leaves it.
- Every proofread now writes one line to a local diagnostic log (outcomes
  and character counts only, never your text), so "it did nothing" always
  has an answer. Find it via Settings > Statistics > Show in Finder.
- Apple Intelligence now appears in Settings > Models alongside the
  downloadable models, with its readiness status - so the full engine
  lineup is visible in one place.
- The Launch at login toggle now explains when macOS refuses it (for
  example when running a copy outside /Applications) instead of showing
  a cryptic system error.
