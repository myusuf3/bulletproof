## What's new in 0.0.23

- Your numbers are protected. A correction that drops or changes a number
  you typed ("300" -> "00", "12" -> "2") is never pasted. Reformatting is
  still fine, so dictating "7 15 am" still gives "7:15 a.m.".
- Fewer good corrections thrown away. Lowercase days and names you type
  ("wednesday") no longer count as misspellings. With Verify corrections on
  (Settings > Engine), the double-check no longer blocks the Bulletproof
  Proofreader's grammar fixes ("eat" -> "eats", "reopen" -> "reopened",
  "closing" -> "to close") or fixes that only move words.
- In our tests, corrections that come through right go from 93.8% to 94.0%
  with default settings, and from 93.5% to 94.0% with Verify corrections on.
